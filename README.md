# 韩语视频工作台

把普通话视频做成带韩语配音和韩文硬字幕的 MP4，同时导出可编辑的 SRT。可以上传本地视频，或通过 KuKuTool 下载分享链接里的原片。支持批量排队、预览和打包下载。

## 从这里开始

1. 有线上账号时，打开 [韩语视频工作台](https://hanyu.xzggai.com/) 并登录。
2. 在自己的 Mac 上运行时，先按 [首次安装](workbench/README.md#macos-首次安装) 准备依赖和模型，再双击 **打开韩语视频工作台.command**，访问 [本机工作台](http://127.0.0.1:8790/)。
3. 在「导入视频」粘贴分享链接或选取本地视频。选好配音和原字幕处理方式，点击「开始生成」。在处理队列预览并保存成片与字幕。

[完整使用说明](workbench/README.md) 包含 HeyGen 配置、原字幕和右下角角标处理、二虎口型修订流程、排错以及 Linux 部署入口。

仓库提供源码和启动脚本。运行时文件、API Key、模型、原片和视频成片由使用者在本机或部署环境中准备。
